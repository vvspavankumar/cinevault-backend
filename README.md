# 🎬 CineVault

🔗 **Live Demo:** https://cinevault-backend-8jyx.onrender.com/

CineVault is a full-stack movie review platform where users can search movies, create accounts, and share reviews.

## ✨ Features

* User Registration & Login
* JWT Authentication
* Search Movies
* View Movie Details
* Add & Read Reviews
* Responsive UI

## 🛠️ Tech Stack

* HTML, CSS, JavaScript
* Node.js, Express.js
* MySQL
* JWT & bcrypt
* Render & Railway

## 🚀 Run Locally

```bash
npm install
npm start
```

## 📌 Project Goal

Create a simple platform for movie enthusiasts to explore movies and share reviews.
